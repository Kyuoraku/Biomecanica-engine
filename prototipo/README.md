# Prototipo

`index.html` es el prototipo v2 (3D + capa de músculos), un solo archivo con Three.js r160 desde jsDelivr. Es la referencia visual y de comportamiento de la SPEC; el proyecto real se construye desde cero con la arquitectura de `docs/03 - SPEC técnica.md`.

- Publicado: https://claude.ai/artifact/TuV7PaNVL7xhunw5dERqSb
- Abrirlo local: servirlo con cualquier servidor estático (por ejemplo `npx serve prototipo`), porque los módulos ES no cargan desde `file://`.
- `capturas/`: sentadilla lateral, sentadilla 3/4 con músculos, RDL con solo activos, escápulas en vista posterior y pelvis.
